# Как запустить
1) Перейдите в корень репозитория.
2) Запустите команду (пример для VOC‑подобного датасета):

python -m searchdet_pipeline.eval_classes.typer_cli /path/to/config.yaml

## Что надо сделать,чтобы изменить VOC на любой другой формат?
- Написать класс ,который будет наследоваться от Dataset
- Внедрить использование класса в typer_cli
- Done,вернуться к запуску(читай выше)
