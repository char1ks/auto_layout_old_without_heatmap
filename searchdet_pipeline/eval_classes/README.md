# Как запустить
## Быстрый старт
1) Перейдите в корень репозитория.
2) Запустите команду (пример для VOC‑подобного датасета):

python -m searchdet_pipeline.eval_classes.typer_cli /path/to/dataset 

Минимум, что нужно знать про параметры:
- dataset_dir — корень VOC‑подобного набора. Если внутри уже есть Annotations и JPEGImages, флаги можно не указывать.
- --ann-dir — путь к XML‑аннотациям (опционально)
- --img-dir — путь к изображениям (опционально)
- --positive-dir — папка с «эталонными» позитивами (нужна детектору)
- --negative-dir — папка с негативами (опционально)
- --run-name — имя папки с результатами (если не задать, подставится метка времени)

## Что надо сделать,чтобы изменить VOC на любой другой формат?
- Написать класс ,который будет наследоваться от Dataset
- Внедрить использование класса в typer_cli
- Done,вернуться к запуску(читай выше)
